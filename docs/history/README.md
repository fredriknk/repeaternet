# Historical plans and reports

These documents record decisions, benchmarks, implementation milestones, and
browser observations at their stated dates/revisions. They can mention removed
desktop features, old defaults, completed defects, and unverified work.

Use the [current roadmap](../ROADMAP.md), [user guide](../USER_GUIDE.md), and
[development guide](../DEVELOPMENT.md) for current behavior and requirements.

| Record | Evidence retained |
| --- | --- |
| [RF engine plan](RF_ENGINE_PLAN.md) | RF/search milestones, larger/long-distance search measurements, scaling investigation |
| [Usability/performance plan](USABILITY_PERFORMANCE_PLAN.md) | Existing-router selection, terrain preparation, persistence and resource work |
| [Mesh coverage plan](MESH_COVERAGE_PLAN.md) | Coverage contracts, scenario/target/report work, sampling and replay measurements |
| [UI workflow plan](UI_WORKFLOW_IMPROVEMENT_PLAN.md) | Initial web workspace redesign |
| [UI simplification plan](UI_SIMPLIFICATION_PLAN.md) | Help disclosures, direct actions, Map/Analysis separation |
| [UI fix plan](UI_FIX_IMPLEMENTATION_PLAN.md) | Navigation, presets, comparisons, archive/restore and Analysis fixes |
| [Browser usage report, 2026-09-29](UI_USAGE_REPORT_2026-09-29.md) | Real Oslo terrain observations and explicit acceptance gaps |

Raw [benchmark artifacts](../benchmarks) and [terrain provenance](../REAL_TERRAIN_FIXTURE.md)
remain outside this folder so new measurements can use the same fixtures.
