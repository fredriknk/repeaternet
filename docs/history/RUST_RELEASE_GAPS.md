## Current status (2026-11-20)

The initial findings below are retained as a historical review. Since that review:

- Trusted-proxy HTTPS and Secure cookies, bounded upload admission, dedicated report exports, provider and saved-coverage HTTP wiring are implemented and covered by integration tests.
- Project-store startup recovery reconciles interrupted filesystem publication against the committed SQLite catalog.
- Terrain supports 450 registered projected metre CRSs and ten custom projection methods. Full Rasterio format/CRS compatibility remains open; see the terrain crate README.
- Python identity hashing is checked against 3,288 golden cases. Historical Python coverage is readable and comparable when compatible, but remains stale and is never reused as native RF output.
- The Windows workspace, strict lint checks and isolated executable verifier pass. The raster performance regression was fixed with byte-identical benchmark output.

Remaining release checks: clean-machine Explorer launch, interactive browser workflows,
live-provider checks, broader terrain compatibility, and recovery from a corrupt current
coverage manifest. Isolated same-machine verification is not a clean-machine test.
See [current application scope](../../rust/README.md) and [release validation](../RELEASE_VALIDATION.md).

Verify Kartverket route and supplemental terrain preparation, Overpass road access and overlays, CoreScope import, full coverage lifecycle, point inspection, failure/height scenarios, run and target comparison, target assessment, and coverage downloads as the integrations land. The [fallback](https://github.com/fredriknk/repeaternet/blob/38c48a8/rust/crates/web-server/src/server.rs#L45) returns 501 for unwired API paths. Include Python discovery endpoints from the migration inventory in the API contract review.
- Historical metadata currently presents saved coverage as stale in the preview. Require actual compatibility/currentness checks after wiring using the copied Python run and target report trees. Preserve job and chunk identity, ordering, stale reason, partial gating, restart interruption and scope isolation. Verify cross-runtime durability on copies preserving file metadata and copies where metadata changes.
- Baseline scope already excludes retired Qt, desktop formats, the legacy Deygout model and opportunistic import of loose pre-catalog files. Native implementation, embedded assets, stronger loopback Host validation and a user-writable direct-launch default are compatible changes provided existing deployment flags, data overrides, stable browser origin and workspace reopening still work. The narrowed CRS set and loss of HTTPS behavior require fixes for full preservation.

## Core parity observations

- Reviewed the Python and Rust RF defaults and web merge path in [Python settings](https://github.com/fredriknk/repeaternet/blob/18b7cee/src/rf_router_planner/models/settings.py#L36), [Rust settings](https://github.com/fredriknk/repeaternet/blob/38c48a8/rust/crates/rf-core/src/settings.rs#L121), and [route_inputs.rs:406](https://github.com/fredriknk/repeaternet/blob/38c48a8/rust/crates/web-server/src/route_inputs.rs#L406). The inspected defaults agree on 869.5 MHz, −130 dBm, propagation validation, and the LoRa manual override. Rust applies a single Bullington model via the web contract. Gate all embedded defaults against Python and rerun directional fixtures with asymmetric endpoint and client values, automatic LoRa sensitivity, strict LOS and DOM fallback.
- Coverage cell precedence agrees in the inspected paths, with valid service first, profile cap unresolved next, terrain unknown next, and definitive uncovered last. Rust derives directional values from the RF link and suppresses validity on strict structural failure. Keep [engine.rs:334](https://github.com/fredriknk/repeaternet/blob/38c48a8/rust/crates/coverage/src/engine.rs#L334) and the [Python-backed grid test](https://github.com/fredriknk/repeaternet/blob/38c48a8/rust/crates/coverage/tests/parity.rs#L36) in the release suite. Add end-to-end replay with one positive source alongside unknown and unresolved sources, a one-way-only link, a ground gap, and a canceled partially sampled cell. Check the same distinctions in stored pages, inspection, comparison and exports.
- Route work reserves an outstanding slot before preflight and verifies the captured identity before publishing. Coverage preview reserves a worker and rechecks route identity afterward. [Route race tests](https://github.com/fredriknk/repeaternet/blob/38c48a8/rust/crates/web-server/src/route_http_tests.rs#L467) cover deterministically gated snapshot work. Run integration races across project change, autosave, terrain publication, alternate selection, queue saturation, ordinary cancel and stop-and-keep once all jobs share admission and publication rules.
