      Help: search effort

      Every effort level checks every plausible link between candidate sites and returns the strongest route for each router count, then refines router positions. Quick and Balanced use fewer candidate sites and may miss a better hilltop. Thorough uses your configured candidate limit (5,000 by default) and can take a minute on large areas.

      Estimate where a handheld could reach this selected network. This is a terrain-based link prediction, not measured coverage or packet-delivery reliability.
